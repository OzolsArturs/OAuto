 # OAuto e-komercijas projekts

## Projekta apraksts
Šis ir e-komercijas projekts, kas izveidots, izmantojot WordPress un WooCommerce. Vietne darbojas uz DigitalOcean servera, izmanto Cloudflare DNS/CDN un HTTPS ar Let's Encrypt sertifikātu.

## Publiskā saite
https://oauto.me

## Tehnoloģijas
- WordPress
- WooCommerce
- Apache
- PHP
- MySQL
- DigitalOcean
- Cloudflare
- Let's Encrypt

## Funkcionalitāte
- Produktu katalogs 
- Pirkuma plūsma (cart - checkout - order)
- E-pasti pēc pasūtījuma
- PDF rēķini
- HTTPS un Cloudflare

## Runbook

### Servera izveide
- Izveidot DigitalOcean droplet
- Pieslēgties ar SSH

### WordPress uzstādīšana
- Instalēt WordPress
- Uzstādīt WooCommerce

### Domēns un SSL
- Pievienot domēnu Cloudflare
- Uzlikt SSL ar Certbot

### Testēšana
- Izveidot testa pasūtījumu
- Pārbaudīt e-pastu
- Pārbaudīt PDF rēķinu
